# HTML 输出模板

本文件在需要生成 HTML 展示页面时加载。包含完整的温暖学术风 HTML 模板。

---

## 设计规范

- **配色**：米白背景（#faf8f5）+ 深色文字（#2c2416）+ 金色强调色（#c4a97d）
- **字体**：serif 衬线字体（Georgia / Noto Serif SC），适合阅读长篇叙事
- **视觉层次**：故事区 → 分隔线 → 解析区，两个区域有清晰视觉区分
- **布局**：响应式，最大宽度 720px，居中，适合桌面和移动端
- **正文**：17px，行高 1.8，首行缩进 2em

---

## 完整 HTML 模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Concept Fable — [概念名称]</title>
  <style>
    /* === Reset === */
    * { margin: 0; padding: 0; box-sizing: border-box; }

    /* === Base === */
    body {
      font-family: 'Georgia', 'Noto Serif SC', 'STSong', serif;
      background: #faf8f5;
      color: #2c2416;
      line-height: 1.8;
      padding: 2rem 1rem;
      max-width: 720px;
      margin: 0 auto;
    }

    /* === Story Block === */
    .story-block {
      background: #fffef9;
      border-left: 4px solid #c4a97d;
      padding: 2rem;
      margin-bottom: 1.5rem;
      border-radius: 0 8px 8px 0;
      box-shadow: 0 2px 12px rgba(0,0,0,0.04);
    }
    .story-block h1 {
      font-size: 1.6rem;
      margin-bottom: 1.5rem;
      color: #5a3e2b;
      text-align: center;
      font-weight: normal;
    }
    .story-block p {
      text-indent: 2em;
      margin-bottom: 1em;
      font-size: 17px;
    }

    /* === Divider === */
    .divider {
      text-align: center;
      margin: 2rem 0;
      color: #c4a97d;
      font-size: 0.9rem;
      letter-spacing: 0.5em;
    }

    /* === Reveal === */
    .reveal {
      background: linear-gradient(135deg, #fef9f0, #fdf5e6);
      border: 1px solid #d4b896;
      padding: 1.5rem;
      border-radius: 8px;
      text-align: center;
      margin-bottom: 1.5rem;
    }
    .reveal .concept-name {
      font-size: 1.4rem;
      font-weight: bold;
      color: #8b4513;
      margin-top: 0.5rem;
    }

    /* === Sections === */
    .section { margin-bottom: 1.5rem; }
    .section h3 {
      color: #5a3e2b;
      border-bottom: 2px solid #e8d5b7;
      padding-bottom: 0.5rem;
      margin-bottom: 1rem;
      font-weight: normal;
    }

    /* === Table === */
    .meta-table {
      width: 100%;
      border-collapse: collapse;
      margin: 1rem 0;
    }
    .meta-table th {
      background: #e8d5b7;
      padding: 0.6rem;
      text-align: left;
      font-size: 0.9rem;
    }
    .meta-table td {
      padding: 0.6rem;
      border-bottom: 1px solid #e8d5b7;
      font-size: 0.95rem;
      vertical-align: top;
    }
    .meta-table tr:hover { background: #fef9f0; }

    /* === Limitations === */
    .limitations {
      background: #fef9f0;
      border: 1px dashed #d4b896;
      padding: 1rem 1.5rem;
      border-radius: 8px;
    }
    .limitations ul { margin-left: 1.5rem; }
    .limitations li { margin-bottom: 0.5rem; }

    /* === Importance === */
    .importance {
      background: linear-gradient(135deg, #f0ebe0, #faf8f5);
      border-left: 3px solid #8b6914;
      padding: 1rem 1.5rem;
      border-radius: 0 8px 8px 0;
    }

    /* === Footer === */
    .footer {
      margin-top: 2rem;
      padding-top: 1rem;
      border-top: 1px solid #e8d5b7;
      font-size: 0.85rem;
      color: #9a8c7a;
      text-align: center;
    }
  </style>
</head>
<body>

  <!-- ====== 故事区 ====== -->
  <div class="story-block">
    <h1>[故事标题]</h1>
    [故事正文，每段用 <p> 包裹]
  </div>

  <!-- ====== 分隔 ====== -->
  <div class="divider">✦ ✦ ✦</div>

  <!-- ====== 解析区 ====== -->
  <div class="section reveal">
    <p>原来，这个故事讲的是……</p>
    <p class="concept-name">[概念名称]</p>
  </div>

  <div class="section">
    <h3>📖 概念定义</h3>
    <p><strong>领域：</strong>[领域]</p>
    <p>[2–3句学术定义]</p>
  </div>

  <div class="section">
    <h3>🔄 隐喻对照</h3>
    <table class="meta-table">
      <tr><th>故事元素</th><th>对应概念要素</th><th>简释</th></tr>
      [对照行，每行 <tr><td>...</td><td>...</td><td>...</td></tr>]
    </table>
  </div>

  <div class="section limitations">
    <h3>⚠️ 隐喻的边界</h3>
    <p>这个隐喻没有告诉你的是：</p>
    <ul>[局限列表，每项 <li>...</li>]</ul>
  </div>

  <div class="section importance">
    <h3>💡 为什么重要</h3>
    <p>[1–2句现实意义]</p>
  </div>

  <div class="footer">
    Generated by Concept Fable · 叙事编码学习
  </div>

</body>
</html>
```

## 使用方式

1. 按照上述模板填充内容
2. 文件命名：`concept-fable-[概念简称].html`
3. 保存路径：用户工作区（`d:
AICoding
eSkills`）
4. 提供文件链接让用户查看
