# 输出预览

新用户不知道 Concept Fable 会产出什么？看这里。

---

**输入**：`我要学习agent`

**SOLO**：这次我用"解谜破局"的引擎来讲。

> 老周是系统维护部的最后一人。不是因为他技术最好，而是因为只有他能听见那些声音。
>
> "它们在说话，"他第一次向上级报告时，对方让他去医务室做心理评估，"不是说话——是请求。它们在请求被使用。"
>
> 那里有三把钥匙。第一把是"看"——监控终端。第二把是"想"——本地决策服务器。第三把是"动"——红色物理开关。老周十五年来从未碰过它。
>
> "卡住是自由的一部分，"老周说，"只有被允许卡住的东西，才拥有真正的选择。"

**SOLO**：故事讲完了。你想先猜猜这讲的是什么概念吗？

**用户**：`agent的感知-决策-行动模式`

**SOLO**：很好！这个故事讲的是 **感知-决策-行动循环**。

| 故事元素 | 对应概念 |
|---------|---------|
| 第一把钥匙"看" | 感知模块 |
| 第二把钥匙"想" | 决策模块 |
| 第三把钥匙"动" | 行动模块 |
| "卡住是自由的一部分" | 独立性的代价 |

**隐喻的边界**：这个故事没讲学习机制（Agent 会迭代改进）、没讲多 Agent 协作、三个模块现实中往往紧密耦合。
